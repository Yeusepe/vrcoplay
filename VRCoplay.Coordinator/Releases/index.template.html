1 of 2 · Install the certificate

  1. Open VRCoplay.Testers.cer from your downloads. Choose Install Certificate….
  2. Select Local Machine → Next and allow the administrator prompt.
  3. Select Place all certificates in the following store, then Browse… → Trusted People → OK.
  4. Choose Next → Finish. Wait for Windows to confirm the import.
Download certificate again

2 of 2 · Install VRCoplay

Open the downloaded file, then choose Install.

Why the alpha needs a certificate

The paid signing plan covers a limited number of builds, so alpha updates use a test certificate.

Adding it to Trusted People lets Windows verify that VRCoplay signed the installer and that it hasn’t changed.

The certificate doesn’t install VRCoplay, run software, change files, or give VRCoplay access to your PC.

When VRCoplay leaves alpha

The public release will use a purchased code-signing certificate. You won’t need to add a certificate yourself.

Avatar pointer

Version {{UNITY_VERSION}} · Unity package · {{UNITY_SIZE}}

Add this package to your avatar to use VRCoplay’s pointer in VRChat. Requires VRCFury.

Download Unity package
Add to an avatar
  1. Open your avatar’s Unity project with the VRChat SDK and VRCFury installed.
  2. Choose Assets → Import Package → Custom Package…, select VRCoplay.Pointer.unitypackage, then choose Import.
  3. In Assets/VRCoplay/Pointer, drag VRCoplayPointer.prefab onto your avatar’s root object in the Hierarchy.
  4. Build and upload the avatar with the VRChat SDK. VRCFury adds the pointer menu and controls during the build.

To update an existing pointer, import the newer package into the same project and upload the avatar again. Keep one pointer prefab on the avatar.

Installation help

If the installer won’t open

If Windows doesn’t recognize the file, get App Installer from Microsoft, then open VRCoplay.appinstaller again.

If the certificate isn’t trusted, return to Certificate setup and select Local Machine → Trusted People.

After installation

Open VRCoplay from Start. You can skip controller setup and start sharing.

VRCoplay offers app updates when you open it. Manage them in Settings → Updates. Avatar updates need to be imported in Unity and uploaded again.
